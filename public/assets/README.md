# Asset Placeholder Guide

This folder contains placeholder images for the STREETWEAR CO. e-commerce site.

## Required Images

### Graffiti Textures
- **graffiti-1.png** (1920x1080px) - Main graffiti background texture
  - Use dark, gritty graffiti wall texture
  - Will be used at 15% opacity with overlay blend mode

- **graffiti-2.png** (1920x1080px) - Secondary graffiti overlay
  - Different graffiti style or angle
  - Will fade in on product card hover

### Product Images
- **shirt-1.png through shirt-8.png** (800x1000px each)
  - Aspect ratio: 4:5
  - Transparent background recommended
  - Show t-shirt flat lay or on model
  - High quality product photography

- **placeholder-shirt.png** (800x1000px)
  - Generic t-shirt placeholder
  - Used as fallback when images fail to load
  - Simple, clean design

### Brand Assets
- **logo.png** (200x200px minimum)
  - Transparent PNG
  - Brand logo/wordmark
  - High contrast for visibility on dark backgrounds

### Optional Assets
- **smoke-layer.png** (1920x1080px)
  - Wispy smoke texture
  - Very transparent (10-20% opacity)
  - Used in hero section

## Image Specifications

### Format
- PNG with transparency (preferred)
- JPG for photographs without transparency
- Optimize for web (compress to under 500KB each)

### Naming Convention
- Use lowercase
- Use hyphens for spaces
- Match the names exactly as listed above

## Temporary Placeholders

Until you add real images, the site will:
1. Show broken image icons
2. Fall back to placeholder-shirt.png for products
3. Continue to function without images

## Where to Find Images

### Free Stock Photos
- Unsplash.com (search: "streetwear", "graffiti", "urban")
- Pexels.com (search: "t-shirt mockup", "street art")

### Create Your Own
- Use Canva.com for mockups
- Use Photoshop/GIMP for graffiti textures
- Use Blender/Cinema4D for 3D product renders

### AI Generation
- Midjourney: "/imagine graffiti wall texture dark urban"
- DALL-E: "Dark graffiti wall texture, urban street art"
- Stable Diffusion: "streetwear t-shirt mockup, premium quality"

## Quick Setup

1. Add your images to this `/public/assets/` folder
2. Name them exactly as specified above
3. Refresh your browser
4. Images will automatically appear on the site

No code changes needed!
